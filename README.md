# 样条流程工具箱

3ds Max 样条线效率工具（MaxScript）。

## 功能概览

- 描摹样条线（支持多选，保留曲线切线）
- 批量附加（样条 / Editable Poly）
- 炸开到对象
- 交点加点（选两条线自动在交点处加点）
- 一键挤出
- 一键加壳
- 精简样条点（容差 + 焊接阈值）
- 重置轴（仅影响轴，居中到对象）
- 归零到世界0（XY归零，Z按最低点贴地）
- 复制 / 粘贴（临时文件方式）
- 材质批处理（统一材质、按材质名自动重命名对象、颜色）
- 冻结/隐藏快捷操作
- 显示当前选择统计（点/线/面）
- 记录窗口上次位置
- 插件内重载按钮

## 环境

- 3ds Max 2024（中文环境已验证）

## 使用方法

1. 直接把 `样条流程工具箱-codex.ms` 拖进 3ds Max 视口运行  
2. 或：`脚本 -> 运行脚本`，选择 `样条流程工具箱-codex.ms`

## 开机自动加载

先在 3ds Max Listener 中执行：

```maxscript
getDir #userStartupScripts
```

在返回的目录里新建文件 `load_toolbox.ms`，内容：

```maxscript
try(fileIn @"<你的脚本实际路径>\样条流程工具箱-codex.ms" quiet:true)catch()
```
